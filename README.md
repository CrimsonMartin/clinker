# Citation Linker 🔗

> Follow research paper citations seamlessly and organize your research with annotations

Citation Linker is a powerful browser extension that helps researchers, students, and academics organize their research workflow by creating visual citation trees, adding voice annotations, and syncing across devices.

## ✨ Features

### 🌳 **Visual Citation Trees**
- Create hierarchical trees of research papers and web sources
- Drag & drop to reorganize your research structure
- Visual representation of citation relationships

### 🎤 **Voice Annotations**
- Add voice notes to any highlighted text
- Speech-to-text conversion for easy note-taking
- Audio playback of recorded annotations

### 🔄 **Cross-Device Sync**
- Cloud synchronization through a small self-hosted API (see [docs/API.md](docs/API.md))
- Access your research from any device
- Email/password accounts; delete your account and all synced data at any time

### 🔍 **Smart Search**
- Search through highlighted content and annotations
- Filter and navigate large research collections
- Find specific information quickly

### 🎯 **Context Menus**
- Right-click any selected text to save citations
- Quick access to annotation features
- Seamless integration with browsing

## 🚀 Installation

### From Extension Stores
- **Chrome Web Store**: *Coming Soon*
- **Firefox Add-ons**: *Coming Soon*

### Manual Installation (Developers)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/crimsonmartin/citation-linker.git
   cd citation-linker
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure the sync server** (optional):
   - By default the extension syncs with `https://clinker.lanerate.io`
   - To use your own server, `cp .env.example .env` and set `API_BASE_URL`
   - See [Sync Server](#-sync-server) below

4. **Build the extension**:
   ```bash
   npm run build
   ```

5. **Load in browser**:

   **Chrome/Edge:**
   - Open `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" and select the project folder

   **Firefox:**
   - Open `about:debugging`
   - Click "This Firefox" → "Load Temporary Add-on"
   - Select `manifest.json` from the project folder

## 🔧 Configuration

### 🖥️ Sync Server

Sync and accounts are handled by a small self-hosted API; the contract is in
[docs/API.md](docs/API.md) and the implementation lives in `server/`.

Build-time settings come from `.env` (all optional, see `.env.example`):

| Variable | Default | Purpose |
|----------|---------|---------|
| `API_BASE_URL` | `https://clinker.lanerate.io` | Base URL of the sync API |
| `DONATION_URL` | placeholder | "Buy me a coffee" link in the sidebar |

`npm run build` writes `api/config.js` (loaded as `window.CLINKER_CONFIG`).
`npm run build:extension:*` also sets the packaged manifest's `host_permissions`
to the `API_BASE_URL` origin. The root `manifest.json` (used when loading the
project folder unpacked) points at the default server; if you develop against
another server, load `dist-chrome/` or `dist-firefox/` instead.

How it works:
- Sign-in returns a short-lived access token and a refresh token, both kept in
  `storage.local`. The access token is refreshed shortly before it expires and
  once more if a request returns 401; refresh tokens rotate on every use.
- Sync stores one JSON document per user. Uploads send the version they were
  based on; if another device wrote first, the server returns 409 with its current
  document, the extension re-runs its newest-wins decision against it and retries once.
- Signing out revokes the refresh token and clears local research data.
  "Delete Account" on the account page (click your email in the sidebar)
  removes the account and all synced data from the server.

### Permissions Explained

The extension requires these permissions:

| Permission | Purpose |
|------------|---------|
| `activeTab` | Access current webpage for highlighting |
| `storage` | Save citations and settings locally |
| `contextMenus` | Add "Save to Citation Linker" menu |
| `tabs` | Manage extension state across tabs |
| Host access to the sync API origin | Sign-in and sync requests (only the configured `API_BASE_URL`) |
| `scripting` | Inject content scripts (V3) |
| `microphone` | Voice annotation recording |

## 📖 Usage

### Getting Started
1. **Install the extension** and pin it to your toolbar
2. **Sign in** (optional) to enable cross-device sync
3. **Highlight text** on any webpage
4. **Right-click** and select "Save to Citation Linker"
5. **Open the extension** to view your citation tree

### Creating Citation Trees
- **Add citations**: Highlight text and use context menu
- **Organize**: Drag citations to create hierarchical relationships
- **Annotate**: Click annotation bubbles to add voice notes
- **Search**: Use the search function to find specific content

### Voice Annotations
- Click the microphone button when adding annotations
- Speak your notes (speech-to-text conversion)
- Play back audio recordings by hovering over annotation bubbles

### Common Issues
- **Cannot reach the sync server**: Check `API_BASE_URL` in `.env`, rebuild, and confirm `GET /healthz` on the server
- **Microphone not working**: Ensure browser permissions are granted
- **Sync not working**: Sign out and back in; check the server logs and that the extension origin is allowed by CORS
